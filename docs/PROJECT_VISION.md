# Product vision

AXIOM LAB is intended as an **interactive environment for scientific computing and computational discovery**. It is not a chatbot with fabricated calculations and not a generic metrics dashboard.

## Product values

- Genuine computation using validated numerical and scientific libraries.
- Inspectability: show data, method, assumptions, results, warnings, and uncertainty.
- Reproducibility: save input references, frozen configurations, run history, and software versions.
- Learn by building: explain concepts before engineering them, then test and document.
- Accessible usability: modern, calm scientific workspace with progressively revealed controls.

## Current state

Phase 0: architecture and runnable foundation. **No scientific tools are currently implemented.** Original requirements live in `reference/AXIOM_LAB_MASTER_SPECIFICATION.txt`.
