# ADR-003: Use SQLite metadata and local artifact files, beginning in Phase 01

**Status:** Proposed for Phase 0 approval (implementation details may evolve).

## Context

Single-user local project requires simple persistence and dataset traceability.

## Alternatives considered

PostgreSQL/cloud immediately; SQLite plus files.

## Decision

Propose SQLite for metadata, immutable versioned filesystem artifacts. Not implemented in Phase 00.

## Rationale

Small operational footprint; supports later migration.

## Consequences / limits

Will need migrations, backups, lifecycle rules, and local storage limits.
