# ADR-002: Use React/Vite frontend with FastAPI backend

**Status:** Proposed for Phase 0 approval (implementation details may evolve).

## Context

The interface must be interactive, while numerical computation benefits from Python.

## Alternatives considered

Single full-stack JavaScript app; Python desktop app; React/Vite + FastAPI.

## Decision

React/TypeScript/Vite plus Python/FastAPI with versioned HTTP JSON contracts.

## Rationale

Native scientific library access; separation of presentation and computation.

## Consequences / limits

Two local processes and cross-service debugging; document exact startup and API contracts.
