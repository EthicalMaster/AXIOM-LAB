# ADR-001: Use a modular monolith

**Status:** Proposed for Phase 0 approval (implementation details may evolve).

## Context

Single developer, local-first, several related scientific modules.

## Alternatives considered

Microservices; monolith with bounded modules.

## Decision

Start with FastAPI plus independently testable computational modules, one React client.

## Rationale

Less deployment complexity and lower cognitive overhead; boundaries enable later extraction.

## Consequences / limits

Heavy jobs will eventually need isolated workers; avoid direct blocking expensive tasks.
