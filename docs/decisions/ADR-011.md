# ADR-011 — Read-only source quality checks

Status: Candidate pending user verification, Phase 02A.

Purpose: audit missingness and exact source duplicate rows without mutating scientific evidence. File integrity is verified before every analysis. Missing means blank/whitespace-only, not automatically an `NA` token.

Alternatives: pandas.DataFrame.duplicated/dropna is performant and concise, but early automatic dtype and missing-value semantics could hide consequential changes. Database-side duplicate detection would need row-level storage.

Disadvantages: repeated file parsing and SHA-based tracking consume CPU; distinct tracking capped at 10,000, so duplicate counts may be lower bounds. Production requires resource benchmarks, access control and asynchronous workers.
