# ADR-009 — Explicit descriptive numerical contracts

Status: Proposed for user verification (01C)

Decision: compute from immutable, integrity-checked raw data only for consistently numeric columns. Use Python `statistics` with sample and population variance distinguished and type-7 quartiles. Do not coerce mixed columns or impute missing cells.

Alternatives: Pandas/NumPy could provide faster bulk operations but need dtype conventions and dependencies. Browser arithmetic is harder to audit and trust.

Trade-off: repeat-reading source is slower and strict columns may omit useful mixed data; correctness and explainability win initially. Heavy workloads require a new execution design.
