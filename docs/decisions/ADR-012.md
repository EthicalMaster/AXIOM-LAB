# ADR-012 — Fixed equal-width frequency histogram and cautious outlier indicators

Status: Candidate, Phase 02B.

Purpose: allow visual inspection of empirical distributions, separate counts from modelled probabilities, and indicate potential extremes.

Decision: Sturges number of equal-width bins, cap 20, half-open intervals except final inclusive bin. Quartiles use type-7 interpolation (same as 01C), Tukey 1.5×IQR fences when n>=4, explicit warnings for zero IQR.

Alternatives: Freedman–Diaconis bin widths respond to spread but require careful zero-IQR handling; quantile-based bins give unequal widths and would mislead if represented by unnormalized bar heights; kernel density estimation requires bandwidth selection and can suggest unsupported smoothness.

Downsides: binning changes visual impression, Sturges may underresolve multimodality, small-sample Tukey fences are fragile. Current interface uses an accessible exact-frequency table and CSS bars rather than a sophisticated plotting library.

Scale: same 5MiB/50k bound; calculations are synchronous; large datasets require supervised workers and bounded caching.
