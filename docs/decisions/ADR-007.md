# ADR-007 — Bounded dataset imports and immutable original storage

**Status:** Proposed in Bundle 01A, accepted on local verification.

## Context

AXIOM LAB needs its first actual data workflow without silently cleaning files, overwriting raw inputs, or introducing a complex dataset infrastructure. Initial deployment is local single-user.

## Decision

- Use an explicit, versioned `/api/v1/datasets/import` endpoint with server-side size, format and structure checks.
- Parse comma-delimited UTF-8 CSV with Python's `csv` library; XLSX with `openpyxl` in read-only mode; XLS with `xlrd` for legacy Excel.
- Save uploaded **original bytes** once under `runtime/datasets/<opaque-id>/original.<format>` with exclusive file creation, never under a user-provided path.
- Keep metadata in local SQLite, including SHA-256, row/column counts, column names, worksheet and warnings.
- Return only a bounded preview; do not compute statistics or infer types in this milestone.
- Limit input to 5 MiB, 50,000 nonblank data rows and 150 columns. Apply additional XLSX archive size/entry checks.

## Alternatives considered

- **Parse only in the browser:** rejected because server-side computation will later consume the data and browser checks are bypassable.
- **Accept without saving:** rejected because immutable source identity is foundational to reproducibility.
- **Store raw data in database blobs:** deferred; simple file storage makes raw preservation inspectable and keeps SQLite metadata small.
- **Bring in Pandas immediately:** deferred to Phase 01B/01C where data typing, profiling and statistics justify it.
- **Create full SQLAlchemy/Alembic framework now:** deferred until dataset/experiment schemas require managed migrations; this is a small bounded local schema using stdlib `sqlite3`.

## Consequences

- Easy reproducibility and simple local inspection, at the cost of no auth, no multi-user isolation, no database migration framework, and no full job sandbox yet.
- XLSX validation rejects excessively complex archives. This is a mitigation, not a comprehensive malware scanner or execution sandbox.
- First-sheet-only imports must be disclosed; multi-sheet selection is future scope.
- Legacy `.xls` compatibility requires local positive verification with a real sample workbook before acceptance.
