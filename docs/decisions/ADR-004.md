# ADR-004: Introduce a minimal experiment record in Phase 01

**Status:** Proposed for Phase 0 approval (implementation details may evolve).

## Context

First workflow requires saving an experiment but full engine is scheduled Phase 05.

## Alternatives considered

Delay until Phase 05; minimal record now.

## Decision

Introduce experiment ID, dataset version and frozen config/run in Phase 01.

## Rationale

Avoids persistence redesign and protects traceability.

## Consequences / limits

Keep schema minimal and migrate deliberately as advanced features arrive.
