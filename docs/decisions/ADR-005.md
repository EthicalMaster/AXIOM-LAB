# ADR-005: Require structured scientific result and validation contracts

**Status:** Proposed for Phase 0 approval (implementation details may evolve).

## Context

Numerical output alone can be invalid or misleading.

## Alternatives considered

Return bare numbers; typed results with diagnostics.

## Decision

Each implemented method must define its inputs, outputs, assumptions, diagnostics, errors and validation references.

## Rationale

Improves testability, interpretation and scientifically responsible reporting.

## Consequences / limits

More work per feature but justified by scientific correctness.
